# 거울샷 스팟 탐색 앱 PRD

## 1. Why - 목적
- 혼자 활동하는 패션 인플루언서는 촬영 보조 인력이 없어 거울샷으로 착용샷을 대체
- 거울샷 찍기 좋은 장소를 찾기 어려운 문제 존재
- 사용자 간 거울 스팟 정보 공유를 통해 스팟 탐색 문제 해결

## 2. Who - 타깃 사용자
- 개인 활동 패션 인플루언서
- 패션 인플루언서 지망생
- 소규모(팔로워 소수) 패션 인플루언서

## 3. User Flow

### 3.0 로그인
1. 앱 실행 (최초/미로그인 시)
2. 소셜 로그인 (카카오 또는 구글 중 선택)
3. 로그인 완료 → 지도 화면 진입

### 3.1 스팟 탐색 (조회자)
1. 앱 실행
2. 위치 권한 확인 및 현재 위도·경도 조회
3. 현재 위치를 중심으로 지도 표시
4. 현재 위치 기준 주변 거울 스팟 조회 및 마커 표시
5. 지도 이동 시 해당 영역의 거울 스팟 재조회
6. 마커 탭
7. 스팟 상세 화면 진입 (업로드된 사진, 현재 위치와의 거리, 주소 확인)
8. (선택) 길찾기 연동 또는 목적지 확인

### 3.2 스팟 등록 (업로더)
1. 지도 화면에서 '스팟 추가' 버튼 탭
2. 현재 위치 or 지도 상 위치 지정
3. 거울샷 사진 1장 촬영/업로드
4. 스팟명 입력 (선택: 설명 입력)
5. 등록 완료 → 지도에 마커 반영

## 4. 기능 요구사항

### P0 - 핵심 기능
- 소셜 로그인 (카카오, 구글 OAuth2 2종 지원)
- 사용자 식별 (스팟 등록자 구분용 최소 프로필: 닉네임)
- 로그인 세션 유지
- 위치 권한 요청/처리
- 현재 위치 조회 (사용자 현재 위도·경도 조회)
- 현재 위치 기반 지도 표시 (현재 위치를 지도 중심점으로 설정)
- 주변 거울 스팟 조회 및 마커 표시
- 현재 위치와 스팟 간 거리 계산
- 지도 이동 시 해당 영역의 거울 스팟 재조회
- 스팟 상세 조회 (사진, 위치, 거리)
- 스팟 등록 (위치 지정 + 사진 1장 업로드)
- 마커-리스트 연동 없이 지도 단일 뷰 기준 탐색

### P1 - 추가 기능
- 로그아웃/회원 탈퇴
- 마이페이지 (내 등록 스팟 관리)
- 스팟 검색 (지역/키워드)
- 스팟 즐겨찾기
- 스팟별 사진 여러 장 업로드(사용자당 1장 제한 완화)
- 리뷰/평점
- 스팟 신고 기능
- 길찾기 외부 연동 (지도 앱 딥링크)
- 인기 스팟 랭킹

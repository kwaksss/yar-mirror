## D. 예상되는 실패와 확인할 곳

| 증상 | 의심 원인 | 확인 |
|---|---|---|
| 카카오 로그인 화면에서 KOE006 등 redirect 관련 에러 | REST API 키의 리다이렉트 URI 값이 앱이 보낸 값과 다름 | 에러 화면의 값 그대로 콘솔에 등록 |
| 로그인 팝업이 안 닫힘 | `maybeCompleteAuthSession` 동작 안 함(팝업 차단 포함) | 브라우저 팝업 차단 해제, 콘솔 로그 |
| 브라우저 콘솔에 CORS 에러 | 허용 origin 불일치(포트가 8081이 아님 등) | `CORS_ALLOWED_ORIGINS` 또는 접속 포트 확인 |
| 지도가 빈 화면/에러 | JS SDK 도메인에 `http://localhost:8081` 미등록, JS 키 오류 | 콘솔 도메인, iframe 안 콘솔 에러 |
| `POST /auth/login/kakao`가 401 `OAUTH_FAILED` | 토큰 교환 실패(redirect_uri 불일치, client secret, code 재사용) | 백엔드 로그의 `oauth failure detail: status= body=` |
| 로그인은 되는데 닉네임이 `Kakao_xxxxxx` | 동의항목 `profile_nickname` 미설정 | 콘솔 동의항목 |
| 409 `DATA_CONSTRAINT` | 데이터 제약 위반 | 백엔드 로그 |
